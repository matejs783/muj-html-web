GitHub

Pomocí tlačítka níže můžeš publikovat nové změny na GitHub a nasadit je na TrueNAS. Pro správný export html dokumentu je potřeba: být na PC MS, mít spuštěný soubor "C:\Users\MS\Documents\Truenas\start_server.bat" a provést úpravu v Index.html souboru, aby GitHub mohl publikovat novou verzi. Na TrueNASu se pomocí pythonu "server" automaticky smaže starý docker, stáhne se image z Githubu a nainstaluje se s ní nový docker
